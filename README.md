##  1. Taxi Driver Hotspot Prediction & Recommendation System
**Role:** Data Lead  
**Tools:** Python, pandas, NumPy, scikit-learn, Jupyter Notebook, Git  
**Skills:** Data cleaning, EDA, clustering, recommendation systems, predictive modeling, collaboration

### Project Overview
Built an ML-powered companion tool to optimize taxi driver earnings by predicting high-demand zones and recommending optimal pickup locations in real-time.

### Key Components

**Hotspot Model**  
Identifies geographic zones with high customer demand using clustering algorithms and historical trip patterns.

**Scoring Model**  
Ranks potential pickup locations based on:
- Fare potential
- Distance to customer
- Real-time demand levels  
- Trip variability metrics

**Train/Test Strategy**  
Chronological split (Jan–June = train, July–Dec = test) to simulate real-world deployment and prevent data leakage.

### Impact
Provides drivers with actionable recommendations and probability scores for finding their next customer, reducing idle time and increasing revenue potential.

##  3. CAL FIRE Wildfire Structure Damage Prediction
**Tools:** Python, pandas, NumPy, scikit-learn, Matplotlib, Jupyter Notebook  
**Skills:** Data cleaning, EDA, feature engineering, binary classification, model evaluation, risk prediction, data visualization

### Project Overview
Built a predictive model using publicly available wildfire damage inspection data from the California Department of Forestry and Fire Protection (CAL FIRE) to assess structure damage risk.

The dataset includes structures impacted by wildland fires, with outcomes labeled as:
- **No Damage**
- **Destroyed (>50%)**

### Goals
✔ Build an end-to-end prediction system  
✔ Identify key risk factors influencing structure damage  
✔ Train and evaluate machine learning models  
✔ Generate insights that can support emergency response and fire prevention decisions

### Impact
Provides actionable insights for emergency planning and resource allocation, helping prioritize high-risk areas during wildfire events and potentially informing fire prevention strategies and building code requirements.

*Completed as part of a graduate-level Data Analytics course.*
